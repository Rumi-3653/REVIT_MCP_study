BEGINNER GUIDE · 61 SKILLS · 不用會寫程式

跟 AI 講人話，讓 Revit 自己動

這本手冊給第一次接觸 Revit MCP 的人。你只需要會開 Revit、會打字。讀完你會知道：Skill 是什麼、開始前要確認哪三件事、怎麼叫出一個 Skill、它跑起來會經過哪些步驟、什麼時候會停下來問你、以及出問題時先看哪裡。

SECTION 00 · 三分鐘懂

Skill 是什麼？用廚房來比喻

Revit MCP 有三層東西。你不需要全部記住，只要分得出「哪一層在做什麼」：

Skill ＝ 食譜

一份 Skill 就是一份寫給 AI 看的作業流程：先查什麼、再做什麼、哪一步要先給你看預覽、什麼情況要停下來。它不含 Revit 知識本身，只負責「編排」。

Domain ＝ 料理知識

法規第幾條、面積怎麼扣、容差多少、哪些例外。Skill 執行前會先讀對應的 Domain 檔。Skill 和 Domain 講法不一致時，以 Domain 為準。

Tool ＝ 廚具

一支工具只做一件小事：讀目前視圖、列出樓層、改一個參數、建一張圖紙。你不用背工具名字；需要時 Skill 會挑對的去用。

一句話
你不必認識 215 支工具。說出你想完成的事，命中的 Skill 會替你把工具串成一條流程，並且在改模型之前先把要改的東西列給你看。

先認識八個名詞

MCP

Model Context Protocol。AI 和外部軟體（這裡是 Revit）溝通的通用插座。你不用懂細節，知道「有它 AI 才碰得到 Revit」就好。

Skill

一份 SKILL.md 檔，放在專案的 .claude/skills/ 底下。AI 讀它來知道「這類需求該怎麼一步步做」。

Domain

放在 domain/ 的 SOP 文件。法規、公式、注意事項都在這裡；人也看得懂。

Tool（工具）

AI 可以呼叫的最小動作，名字都是小寫加底線，例如 get_all_sheets。

Dry-run（預覽）

「先算給你看，不真的改」。多數會改模型的 Skill 都有這一步，看完你點頭才寫入。

Re-anchor（重新錨定）

每次動手前 AI 都要重新問 Revit「現在開的是哪個視圖、哪一層」，不能用上一輪的記憶。

Transaction／Undo

Skill 改模型都包在 Revit 的交易裡，所以在 Revit 按 Ctrl+Z 可以整批復原。

獨佔連線

同一時間只有一個 AI 客戶端能連著 Revit。第二個會被拒絕，不會把第一個擠掉。

SECTION 01 · 開始之前

三個綠燈：確認完再開口

安裝步驟不在本手冊，請照 部署指南 或 README 的「三步開始」做完。這一節只講每次要用之前要看的三件事。

綠燈 1 · Revit 開著、專案開著

Skill 幾乎都要「目前作用中的視圖」當起點。先把你要處理的專案開起來，切到相關的平面或剖面視圖。

綠燈 2 · Revit 功能區的 MCP 服務是綠燈

Revit 上方功能區有一個 MCP 面板。「MCP 服務」按鈕紅燈＝關、綠燈＝開。沒開就按一下。旁邊的「AI 客戶端」按鈕可以設定只讓 Claude 或 Codex 連，預設是「不限」。

綠燈 3 · AI 客戶端在專案資料夾裡啟動

Skill 是放在這個專案資料夾裡的檔案。Claude Code 要在這個資料夾打開，它才看得到 .mcp.json 和 61 個 Skill。在別的資料夾開，就只是一個普通的 AI。

怎麼知道真的連上了？問一句最簡單的

你現在 Revit 開的是哪個視圖？
AI（示意）我用 get_active_view 查了一下，目前作用中的視圖是 ○○○，類型是樓層平面。

AI 有回視圖名稱，代表「AI 客戶端 → MCP Server → Revit」整條路是通的。如果它回「連不上 Revit」或「找不到 Revit 工具」，直接跳到 SECTION 07。

新手最常卡的地方
  • 服務開了但 AI 說連不上：多半是另一個 AI 客戶端還連著。Revit 功能區按「切換/釋放連線」，再回來重問一次。
  • AI 說找不到工具：Claude Code 不是在專案資料夾啟動，或 MCP Server 還沒 build。看 Troubleshooting。
  • 本手冊以 Claude Code（含 Claude Desktop 的 Code 分頁）為主。Gemini CLI、VS Code Copilot 也能用工具，但不會自動載入這些 Skill。
SECTION 02 · 怎麼叫出來

兩種叫法：講人話，或直接點名

方法 A · 講人話（自然語言觸發）

每個 Skill 的描述裡都寫了觸發關鍵字，中英文都有。你說「房間重新編號」「排煙窗檢討」「把這五張圖的植栽隱藏」，AI 會對上相應的 Skill。

說清楚範圍（哪個視圖、哪幾層、哪幾張圖紙）和要不要先預覽，命中率和結果都會好很多。

方法 B · 斜線點名（最保險）

在 Claude Code 的輸入框打一個 /，會跳出清單，繼續打幾個字母就能篩到你要的 Skill，例如 /room-numbering、/smoke-exhaust。後面可以直接接你的補充，像 /room-numbering 只做 2F。

已經知道名字、或講人話沒命中時，就用這個。

SECTION 03 · 跑起來之後

一次 Skill 執行會經過什麼？

不同 Skill 細節不同，但會改模型的 Skill 幾乎都走同一條骨架。看懂這條，你就知道它什麼時候會停下來、為什麼要停。

用「房間重新編號」走一遍

  1. 觸發

    你說「幫我把 2F 的房間重新編號」，或打 /room-numbering。AI 先讀對應的 Domain 檔，拿到排序規則（樓層前綴、由上到下分排、左到右、各層自 01 起編）。

  2. 健檢（重新錨定）

    AI 查樓層清單、查目前視圖。樓層名字認不出前綴時，它會停下來問你，不會猜。

  3. 盤點

    逐層抓房間清單和位置。沒圍合、抓不到座標的房間，進「例外清單」，不參與編號。

  4. 預覽表

    你會看到一張表：樓層｜房間名稱｜舊編號 → 新編號，加上例外清單。到這裡還沒有任何東西被改。

  5. 你確認

    順序對嗎？前綴對嗎？不對就說「第三排應該在第二排前面」或「B1F 不要做」，AI 重算再給你一張表。

  6. 寫入

    你說 OK，AI 才逐間寫入編號。碰到編號互撞會改用兩段式（先寫暫時編號、再寫正式編號）。

  7. 抽查

    隨機挑幾間回頭讀一次，比對寫進去的值；轉角和不規則隔間會特別看。

  8. 回報

    成功幾筆、例外幾筆、失敗幾筆，各自是哪些。這些數字都來自工具剛剛的回傳，不是 AI 估的。

你幫我把 2F 的房間重新編號
AI（示意）我先依 domain/room-numbering-workflow.md 的規則盤點了 2F。預覽如下（尚未寫入）：
…（表格：房間名稱｜舊編號 → 新編號）…
另外有兩間房間未圍合，列為例外不編號。這樣的順序可以嗎？
你可以，寫入
AI（示意）已寫入。抽查了幾間比對正確。成功／例外／失敗各幾筆如下：…

上面的對話是示意，實際房間名稱、數量以你專案當下工具回傳為準。

SECTION 05 · 手把手

新手最常用的八個情境

每個情境列四件事：你怎麼說、它會做什麼、它會在哪裡停下來問你、要注意什麼。都是從該 Skill 的實際流程整理出來的。

1 · 我想找東西 → /element-query

你說
「這個視圖裡有哪些牆類型？厚度大於 200 的找出來，上紅色。」
它做
先探索目前視圖有哪些類別（探索）→ 查該類別的參數名稱，不猜名字，因為中英文介面和樣板會不同（對齊）→ 用正確名稱篩選（擷取）→ 需要的話上色。
停下來
目標類別在視圖裡不存在、或參數名字對不上時，會先問你。
注意
長度單位是 mm。這個 Skill 只改顯示（上色），不改模型；看完說「清除上色」就恢復。

2 · 我想依參數上色 → /element-coloring

你說
「依防火時效，把這層的牆上不同顏色。」
它做
先清掉舊的顏色覆寫 → 如果對象是牆，先暫時解除牆接合（不然顏色會黏在一起）→ 查參數值分佈、分組 → 每組套一個顏色 → 恢復牆接合。
停下來
配色方案會先跟你討論；參數名稱要先確認。
注意
平面圖用切割樣式、立面圖用表面樣式。房間（Room）不能直接上色，Skill 會改染房間的邊界牆來代替。

3 · 房間編號亂掉了 → /room-numbering

你說
「2F 的房間重新編號。」
它做
見 SECTION 03 的完整走法：健檢樓層前綴 → 盤點 → 排序 → 預覽表 → 你確認 → 寫入 → 抽查。
停下來
樓層前綴認不出來時；預覽表給你看時。
注意
沒圍合的房間會列入例外不編號，報告裡會告訴你是哪幾間。

4 · 一堆視圖要套同一個樣板 → /batch-apply-view-template

你說
「A101 到 A105 這五張圖紙上的視圖，都套『建築平面圖』樣板。」
它做
列出專案裡的視圖樣板跟你對名字 → 用圖紙號、視圖名稱或名稱片段選出目標視圖 → 先 dry-run 列出會被影響的視圖 → 你 OK 才套用。
停下來
dry-run 清單給你看時。
注意
樣板要已經存在於專案裡，Skill 不會幫你建；名稱要完全一致（含中英文、大小寫）。用「名稱包含」選視圖時小心誤選到剖面或明細表，可加視圖類型過濾。

5 · 視圖太亂，想隱藏整類東西 → /view-category-visibility

你說
「這五張平面把植栽跟傢俱隱藏。」
它做
確認目標視圖（目前視圖或依名稱列出多張）→ 對類別名稱（植栽＝Planting、傢俱＝Furniture）→ 逐視圖設定 → 回一張「視圖｜類別｜已隱藏」的表。
停下來
視圖名稱比對有歧義時。
注意
連結模型裡的元素只能整類別隱藏，不能挑單一元素；要挑單一元素請說「隱藏這幾個元素」改走另一支工具。

6 · 要一次建很多圖紙 → /sheet-management

你說
「用 A1 圖框幫我建 A101 到 A110，名稱照這個清單。」
它做
列出可用圖框 → 檢查現有圖號有沒有衝突 → 批次建立。若你是要修圖號衝突（像 -1 後綴），它會用兩段式改名（先暫時名、再最終名）避免互撞。
停下來
圖框選哪一個、圖號有衝突時。
注意
建圖紙會改模型，在 Revit 可以 Undo。重新編號牽涉連鎖位移，先看它列的對照表。

7 · 排煙窗法規檢討 → /smoke-exhaust

你說
「幫我做這層的排煙窗檢討，匯出 Excel。」
它做
先做無開口樓層判定 → 逐間檢查天花板下 80cm 內的可開啟窗面積是否達區劃面積 2% → 自動上色（綠＝合格、黃＝折減後合格、紅＝不合格）→ 匯出 Excel。
停下來
天花板高度要從「房間參數」還是「實體天花」讀，它會先問；窗型係數（推射、推開、橫拉、固定）要跟你對。
注意
這是法規判讀，方法以 domain/smoke-exhaust-review.md 為準。天花還沒建模時用房間參數；畫面和 Excel 必須用同一組設定，否則兩邊數字會不一致。

8 · 照 CAD 圖建柱 → /dwg-column-import

你說
「照這張 CAD 的柱圖層建柱，柱號沿用圖面上的 C1、C2。」
它做
掃描 CAD 圖層 → 預覽：幾根柱、尺寸分佈、放樣範圍，特別是單位健檢 → 跟你選模式（自動建型別／沿用族群尺寸／沿用族群柱號）→ 建柱 → 回報建了幾根、哪些柱號對不上。
停下來
兩個硬斷點：單位健檢有警告時絕不往下；模式與族群要你選，不替你預設。
注意
要在平面視圖執行；CAD 要先匯入或連結；柱輪廓要在獨立圖層。建柱不會自動復原，所以每一步都會等你同意。
SECTION 06 · 為什麼它不會亂動你的模型

四條守則，加上你自己的三個習慣

這些規則寫在專案的 AI 憲法裡，每個 Skill 都遵守。完整說明見 四條憲法。

1 · 連不上就不猜

Revit 沒連上時，AI 只能給一般性建議，不會假裝它看到了你的模型。

2 · 數字都要有來源

回答裡的房間名、ID、面積、數量，都必須來自這一輪工具的回傳。AI 不能用記憶補數字。

3 · 方法照 Domain 走

法規、算量、檢核的公式和扣除規則，以對應的 Domain 檔為準，不用 AI 自己的常識。回答會註明依哪一份。

4 · 每次重新確認現場

目前視圖、樓層、選取都要當下再查一次。上一輪的視圖 ID 不能拿來這一輪用。

你的三個習慣
  • 先存檔。大批次改模型之前存一次。Skill 的寫入可以 Undo，但多一層保險不花錢。
  • 看預覽。看到預覽表不要秒答 OK。花三十秒掃一眼舊值 → 新值和例外清單，這是流程裡唯一給你的剎車。
  • 抽查驗收。AI 會抽幾個驗證，你也在 Revit 裡點兩三個看。不合預期就 Undo，然後把看到的告訴 AI。
AI 不會做、你也別要求它做的事
  • 不會手寫封包繞過 MCP 直接戳 Revit。沒有對應工具的事，正確做法是新增工具，不是硬塞。
  • 不會在兩個 AI 客戶端同時連著 Revit 的情況下工作。要換 AI，先在 Revit 功能區「切換/釋放連線」。
  • 不會替你做法規判斷的最終決定。Skill 給的是依 Domain 算出的結果和依據，簽名的還是你。
SECTION 07 · 出問題怎麼辦

三十秒分流：先找斷在哪一段

#你看到的症狀最可能的原因怎麼處理
1講了半天，AI 自己亂做、沒照 Skill 的流程關鍵字沒對上改用斜線點名：/skill-name 加你的需求。
2AI 說「找不到 Revit 工具」Claude Code 不在專案資料夾啟動；MCP Server 沒 build；客戶端沒重啟在專案資料夾重開 Claude Code；MCP-Server 跑一次 npm run build；重啟客戶端。
3aAI 說「連不上 Revit，請按 MCP 服務（開/關）」Revit 沒開、服務沒開、或 8964 被佔看綠燈 2。埠被卡住時跑 scripts/release-port.ps1。
3bAI 說「被拒絕，請檢查 AI 客戶端或切換/釋放連線」另一個 AI 還連著，或「AI 客戶端」按鈕設成別家Revit 功能區按「切換/釋放連線」，或把「AI 客戶端」改回「不限」。
4跑完了但結果不是你要的範圍講得不清楚；參數名或樓層前綴對錯Revit 按 Ctrl+Z 復原。把你看到的（哪間、哪張圖、差在哪）講給 AI，重新 dry-run。
